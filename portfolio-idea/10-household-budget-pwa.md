# 家計簿 PWA（オフライン対応）

個人向けですが、PWA・オフライン・グラフ・インポートなど「クライアント品質」を厚くできます。フロントエンド志望、またはモバイル Web 志望に向きます。データがセンシティブなので、プライバシー設計も語れます。

## 概要

支出・収入の記録、カテゴリ、月次予算、グラフ、CSV 入出力を持つ家計簿です。Service Worker でオフライン入力でき、オンライン復帰時に同期します。

## 就職活動でのアピールポイント

- PWA（インストール、オフライン、バックグラウンド同期）
- IndexedDB とサーバーの同期コンフリクト
- データ可視化
- フォーム UX、バリデーション
- プライバシー（暗号化、データエクスポート／削除）

## 解決する課題

レシート直後に素早く記録したい。通信が不安定でも入力を失いたくない。月の使いすぎを早く知りたい。

## 想定ユーザー

個人。デモは架空の 3 ヶ月分シード（リアルな家計データは使わない）。

## 主要機能

### 必須（MVP）

- 取引の CRUD（日付、金額、カテゴリ、メモ、支出/収入）
- 月次一覧とカレンダー
- カテゴリ別円グラフ、日次棒グラフ
- 月次予算と進捗バー
- 認証してクラウド同期（任意だがポートフォリオならあった方がよい）

### 推奨

- オフラインキュー、再接続時同期
- 繰り返し取引（家賃）
- 口座・現金の複数ウォレット
- CSV インポート（銀行の出力を簡易マッピング）
- レシート画像（OCR は発展。まずは添付のみ）
- ダークモード、インストール可能 PWA

### 発展

- WebAuthn
- エンドツーエンド暗号化（設計が難しい。やるなら制約を明記）
- 共有家計（世帯）と権限

## 画面構成

| 画面 | 役割 |
| --- | --- |
| 今月サマリー | 予算と残り |
| 取引リスト | フィルタ、無限スクロール |
| 入力 | 大きいテンキー、最近使ったカテゴリ |
| レポート | 月比較 |
| 設定 | エクスポート、アカウント削除 |

## API 概要

- `GET/POST /transactions`（updated_at による差分同期）
- `GET /reports/monthly?month=`
- `POST /sync`（クライアントの変更セット、サーバーの勝ち負けルール）
- `DELETE /me`（カスケード削除）

## 技術スタック（推奨）

| 層 | 候補 |
| --- | --- |
| フロント | Next.js または Vite + React、TypeScript、Tailwind、Recharts、Dexie.js |
| PWA | Workbox、または Serwist |
| バックエンド | Hono / NestJS、PostgreSQL |
| 同期 | 各レコードに `id`（ULID）、`updated_at`, `deleted_at` |
| インフラ | Docker、Vercel + 別 API、GitHub Actions |
| テスト | Playwright でオフライン模擬があると強い |

## アーキテクチャ

ローカル IndexedDB が正（入力の速さ優先）。サーバーはバックアップと他デバイス同期。コンフリクトは `updated_at` の LWW（Last Write Wins）を基本にし、制限を README に書きます。

## データモデル（概要）

- `accounts`（wallet）
- `categories`（user custom）
- `transactions`（amount は整数の円、符号で収支）
- `budgets`（month, category_id, limit_amount）
- `sync_cursors`

金額は浮動小数点を使わず整数（円）にします。

## セキュリティ・品質

- HTTPS 必須（PWA）
- セッション Cookie、CSRF
- 他ユーザーのデータが API で取れないテスト
- デモ環境の「アカウント削除」

## 実装の進め方

1. オンラインのみの CRUD とグラフ
2. PWA インストール
3. IndexedDB とオフライン
4. 同期とコンフリクト方針
5. インポート / エクスポート

## 工数目安

- オンライン MVP: 1.5〜2 週間
- オフライン同期込み: 4 週間

## 面接での話し方

「金額を整数にした理由」「オフラインで削除したレコードを tombstone で送る理由」が良い話題です。実データを入れないこともプライバシー意識として話せます。
