# ライセンスと利用方針

ポートフォリオ一式（メタ `portfolio-plan` と兄弟の `pf-*`）の利用条件の正本要約。  
各リポジトリの法的テキストはルートの `LICENSE`（Portfolio Evaluation License）です。

## 当面の方針

- GitHub リポジトリは **パブリックのまま**（就活・評価のため）
- 公開ソースは **デモ／学習／社内評価用**
- **保証なし**（現状品質・学習用 IdP／架空データ前提）
- **本番運用・商用利用・有償提供・再販**は **別契約が必要**

## 許可される利用（評価ライセンス）

- クローン、ローカル／検証環境での実行
- 学習、採用選考でのコードレビュー
- 社内 PoC・デモ（**実顧客データや対価が発生する本番は不可**）

## 別契約が必要な利用

- 本番環境での運用（実ユーザ／実業務データの処理）
- 有償製品・サービスの一部としての提供
- マネージドホスティング、ホワイトラベル、再配布の対価取得
- ソースの商用再販

## README への載せ方

各 `pf-*` とメタ README に、次の節（同趣旨）を置く。

```markdown
## ライセンスと利用条件

本リポジトリは **デモ・学習・社内評価用** です。現状品質に **保証はありません**。

- 許可: クローン、ローカル実行、学習、非本番の評価
- 別契約が必要: 本番運用、有償サービスへの組込み、再販・托管の提供

詳細は [LICENSE](./LICENSE) と
[licensing.md](https://github.com/maeplego/portfolio-plan/blob/master/portfolio-plan/licensing.md)
を参照してください。
```

## 第三者コンポーネント

依存ライブラリ（例: Expo、Next.js、Go モジュール）は各々のライセンスが優先する。  
本 `LICENSE` はポートフォリオ独自コードの評価条件を定めるものであり、第三者を再ライセンスしない。
