## 1. 背景と目的

レシート直後に素早く記録し、月の使いすぎを早く知りたい。金額の一貫性（整数円）と月次の見え方が中心である。習慣トラッカー [pf-habit-mobile](https://github.com/maeplego/pf-habit-mobile) とは統合しない。通知中心のネイティブ習慣と、金額中心の家計簿は別製品の方が両方強い。

学習用であり、商用家計アプリや銀行接続の置き換えではない。実家計・実カード番号は使わない。

## 2. 含む

- 取引の CRUD（日付、正の整数円、カテゴリ、メモ、支出/収入）
- 月次一覧、カテゴリ円グラフ、日次棒グラフ
- 月次の全体予算と進捗バー
- CSV の書き出しと取り込み（整数円。カテゴリは名前と kind で突合）
- 架空 3 ヶ月シード（2026-06〜08）
- 他ユーザーの取引が API で取れないこと
- PWA としてインストールできること（manifest + Service Worker）
- 単体 Compose（Postgres + API + Web）が通常のデモ経路
- Kubernetes 用マニフェストは ops overlay から参照できるが、起動の正は Compose

## 3. 含まない

| 項目 | 理由 |
| --- | --- |
| IndexedDB が正 / オフラインキュー | 未実装。オフライン新規入力は約束しない |
| `POST /sync`、LWW、tombstone | 未実装。DELETE は即時ハードデリート |
| 繰り返し取引、複数ウォレット | 未実装 |
| 認証基盤の OIDC、アカウント削除、ダークモード | 未実装 |
| 銀行 API、確定申告、世帯権限、E2E 暗号化 | 範囲外 |
| 習慣トラッカーとのデータ統合 | 範囲外 |

## 4. アクター

| アクター | 定義 | 認証 |
| --- | --- | --- |
| 個人ユーザー | 自分の家計だけを見る | `X-Dev-User-Sub` |
| デモユーザー `demo` | 架空シードが入る | 同上 |

## 5. 前提

- ID は ULID。金額は整数円。DB 時刻は `timestamptz`（UTC）。取引日は `DATE`（暦日）
- 通貨は JPY 固定
- 一人 1 家計。共有世帯は発展
- HTTPS 前提。localhost は PWA の例外

## 6. 機能要件

| ID | 要件 | なぜ |
| --- | --- | --- |
| FR-01 | 金額は正の整数円。浮動小数は 400 | 円の一貫性 |
| FR-02 | 取引 CRUD は所有者だけ。他人の ID は 404 | 認可。存在を 403 で漏らさない |
| FR-03 | 月次レポートは収入・支出・差引・カテゴリ・日次を整数で返す | グラフの入力 |
| FR-04 | 月次予算（全体）と残り（予算 − 支出） | 使いすぎを早く知る |
| FR-05 | `demo` に架空 3 ヶ月が入る。実データではない | デモとプライバシー |
| FR-06 | Web はインストール可能な PWA | クライアント品質 |
| FR-07 | 自分の選択月だけ CSV を書き出せ、取り込める。取り込みは元 id を漏らさない | バックアップと移行 |

## 7. 非機能

| ID | 要件 | なぜ |
| --- | --- | --- |
| NFR-01 | 純論理と HTTP テストは DB なしで緑 | CI が Docker 無しでも回帰する |
| NFR-02 | Compose は専用 Postgres。レビュアの既定経路は Compose | 単独デモ |
| NFR-03 | README に学習用・実家計なし・既知の制限を書く | 誤用と過大広告を防ぐ |
| NFR-04 | HTTPS 前提。localhost は PWA の例外 | 仕様 |
| NFR-05 | K8s マニフェストは overlay 経由。このフォルダだけを apply しない | 連携デモの束ね |

## 8. 受け入れ

1. `demo` の 2026-06 支出が 97780 円、収入 280000 円、予算残り 102220 円
2. `amountYen: 12.5` の POST が 400
3. ユーザー A の取引を B が list / get / delete できない（404 または空）
4. Web で月を切り替え、取引追加、グラフ表示、CSV 入出力ができる
5. `manifest.webmanifest` と Service Worker があり、localhost でインストールできる
6. `docker compose up` で上記が動く
