| 項目 | 値 |
| --- | --- |
| プロジェクト | P12 reliability-platform |
| 対象スライス | 受け入れはインシデントと webhook。訓練セッション API は計画 |
| 最終更新 | 2026-08-19 |
| 矛盾時の正 | 自動テストと製品コード、次に `DESIGN.md` |

「今の障害」と「判断の練習」を 1 製品にする。本番クラスタは操作しない。学習用。

含む: サービスマスタ、インシデント CRUD、Ack/Resolve、コメント、HMAC webhook、dedup_key 集約、画面に「本番システムは操作しません」、仮想メトリクス GET、シナリオ純関数（scale では直らず rollback で回復）。

含まない: 自動 rollback ボット、実 kubectl、PagerDuty 互換、公開ページング、オンコール週次（計画）。

受け入れ: 同じイベント 2 回でインシデント 1 件、署名無し 401、resolved のあと同一 dedup は新規、画面文言。
