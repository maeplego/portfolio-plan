# P03 要件定義書

| 項目 | 値 |
| --- | --- |
| プロジェクト | P03 media-platform |
| 対象スライス | 受け入れはローカルドライブ。ウイルススキャンと動画は含めない |
| 最終更新 | 2026-08-19 |
| 矛盾時の正 | 自動テストと製品コード、次に `DESIGN.md` |

## 1. 目的

オブジェクト本体と画像派生を共有基盤にする。Wiki / 商品 / ブログ / チャットがそれぞれ S3 クライアントを再実装しない。学習用であり、本番 CDN の置き換えではない。

## 2. 含む / 含まない

含む: presign PUT、complete、クォータ、フォルダ、共有リンク（期限）、画像ジョブ（orig EXIF 除去、detail 1920 WebP、thumb 320）、マイドライブ UI、dev 認証または P01 OIDC。

含まない: クライアント E2E 暗号化、動画トランスコード、任意 URL fetch（SSRF）、ウイルススキャン（種別制限で代替）、本番 Lambda イベント駆動。

## 3. アクター

所有者（sub）、共有リンクのゲスト（トークン）、processor（内部トークン）、将来の P04/P06/P08（purpose）。

## 4. 機能要件

| ID | 要件 | なぜ |
| --- | --- | --- |
| FR-01 | 実体はアプリメモリを通さない（presign） | 巨大アップロード |
| FR-02 | 権限の正はメタデータ DB。バケット非公開 | 推測 GET |
| FR-03 | 画像処理は非同期 | タイムアウト |
| FR-04 | key は `user/{sub}/ulid` | path traversal |
| FR-05 | クォータ超過は complete 拒否 | 課金相当の学習 |
| FR-06 | 公開共有に他人のファイル名一覧を出さない | PII |

## 5. 受け入れ

1. ブラウザから画像を投げ、数秒後にサムネイル
2. 巨大画像が 413
3. 共有リンクでダウンロードでき、期限切れは 4xx
