## 1. 背景と目的

技術記事はポートフォリオそのものになる。Git に Markdown を置くだけでは下書きと公開の境界が無い。一方で短縮リンクの 302 をブログの Node プロセスに載せると、キャッシュ向けの公開サイトと、悪用耐性が要るホットパスが混ざる。

P08 は **公開コンテンツ基盤** として、ブログ CMS と短縮を同じ製品にまとめ、プロセスだけ分ける。学習用であり、本番 CMS や Bitly の置き換えではない。

## 2. スコープ

### 含む（スライス 1 で満たす）

- Markdown 記事 1 本以上（架空コンテンツ。実在 PII なし）
- 下書きと公開。公開 URL では下書きが 404
- 編集者だけが下書きをプレビューできる
- 短縮の作成 API と `GET /:code` の 302
- クリック件数はリダイレクトを待たない
- デモ用の宛先ホスト許可リスト。`javascript:` 拒否
- 単体 Compose（`pf-content-infra`）でブログ + 短縮が動く
- 画像はローカル `/public` または URL 文字列（P03 任意）

### 含まない（意図的）

| 項目 | 理由 |
| --- | --- |
| overlay E / K8s | 任意の連携デモ。Compose が正。P11 は未搭載 |
| P01 OIDC | 開発ヘッダ / cookie で開始 |
| P03 実パイプライン | ソフト依存。ローカル画像で足りる |
| MDX、OG 画像、Draft Mode、全文検索 | DESIGN 実装順 3 以降 |
| コメント、ニュースレター | スパム。非目標寄り |
| マルチテナント独自ドメイン短縮 | DESIGN 非目標 |
| 生 IP の長期保存 | プライバシー |

## 3. アクター

| アクター | 定義 | 認証（現状） |
| --- | --- | --- |
| 読者 | 公開記事を読む。短縮を踏む | なし |
| 編集者 | 下書き・公開・短縮作成 | `CONTENT_DEV_AUTH` + cookie / `X-Dev-User-Sub` |
| システム（短縮） | 302 と非同期クリック | — |

## 4. 前提・制約

- ID は ULID。DB 時刻は `timestamptz`（UTC）
- 記事スラッグと短縮コードの名前空間は混ぜない
- 一人開発。ブログは Next.js、短縮は Go、Compose は `pf-content-infra`
- シードは架空の Harbor Press

## 5. 機能要件

| ID | 要件 | なぜ |
| --- | --- | --- |
| FR-01 | 公開一覧・詳細は `published` かつ `published_at <= now` だけ | 下書き漏洩 |
| FR-02 | 下書きの公開 slug は 404。プレビューは編集者のみ | DESIGN デモ「非公開のまま見られる」 |
| FR-03 | 記事 CRUD（title, slug, Markdown, tags, 公開日時） | idea 07 MVP |
| FR-04 | RSS と sitemap は公開記事のみ | SEO に下書きを載せない |
| FR-05 | 短縮コードは予測困難。連番禁止。数字のみのカスタム slug も禁止 | 列挙 |
| FR-06 | 宛先は http(s) のみ。許可ホスト以外は拒否 | オープンリダイレクト / フィッシング |
| FR-07 | `GET /:code` は 302。クリック記録は応答後 | ホットパス |
| FR-08 | 管理画面は robots で拒否 | 検索エンジンに載せない |
| FR-09 | 公開記事の短縮 URL を管理から作れる | 統合 UX |

## 6. 非機能要件

| ID | 要件 | なぜ |
| --- | --- | --- |
| NFR-01 | 短縮の純論理と httptest は DB なしで緑 | CI |
| NFR-02 | 生 IP をテーブルに残さない | idea 09 |
| NFR-03 | README に学習用である旨 | 本番誤用 |
| NFR-04 | Compose 必須。overlay E は任意の連携デモ（P08 のみ。P11 なし） | 12 GB |

## 7. 受け入れ（スライス 1）

1. 公開記事 `why-redirect-is-not-nextjs` が読める
2. 下書き `notes-on-scheduled-posts` の公開 URL が 404
3. 編集ログイン後にプレビューでき、Publish すると公開される
4. 許可ホスト向け短縮が 201、`javascript:` と許可外ホストが 400
5. `GET /:code` が 302 で記事 URL へ
6. `docker compose up`（`pf-content-infra/deploy`）で上記が再現できる
