# 要件定義書

| 項目 | 値 |
| --- | --- |
| プロダクト | 習慣トラッカー（モバイル [pf-habit-mobile](https://github.com/maeplego/pf-habit-mobile)、同期 API [pf-habit-api](https://github.com/maeplego/pf-habit-api)） |
| 最終更新 | 2026-08-19 |
| 実装との関係 | この文書と実装が違うときは、製品リポジトリのコードとテストを優先する |

## 1. 背景と目的

毎日の小さな習慣を「今日できたか」で支え、続けている実感（ストリーク）を暦日で正しく出す。Web ばかりのポートフォリオとの差別化として、端末ローカル DB と日付境界を見せる。家計簿 [pf-finance](https://github.com/maeplego/pf-finance) とは統合しない。

学習用であり、商用習慣アプリの置き換えではない。実在人物のログは使わない。**モバイルアプリも同期 API も Kubernetes に載せない。**

## 2. 含む

- 習慣の CRUD（頻度: 毎日 / 週 n 回）
- 当日のチェックと取り消し（端末 SQLite）
- ストリークと月次カレンダー（純関数 + TZ / 年末テスト）
- 統計画面（直近 30 日の完了数・完了率と現在ストリーク）
- 架空 5 習慣 × 30 日シード
- 任意の薄い同期 API（Compose）。他ユーザーの習慣が取れないこと
- いまの Expo アプリは API を呼ばない。オフラインでも記録できる

## 3. 含まない

| 項目 | 理由 |
| --- | --- |
| ローカル通知 | 未実装 |
| モバイル → API の同期クライアント | 未実装。API は Compose デモ用 |
| 認証基盤の public + PKCE | 未実装 |
| Watch、ソーシャルランキング、ヘルスケア | 範囲外 |
| 家計簿とのデータ統合 | 範囲外 |
| モバイル / API の Kubernetes 搭載 | 意図的に載せない |
| 履歴改ざん防止、アーカイブ UI、CSV | 未実装 |

## 4. アクター

| アクター | 定義 | 認証 |
| --- | --- | --- |
| 個人ユーザー（端末） | 端末 SQLite の習慣だけを見る | なし（ローカル） |
| API ユーザー | 自分の習慣だけ | `X-Dev-User-Sub` |
| デモユーザー `demo` | 架空シード | 同上 |

## 5. 前提

- 「今日」はユーザー TZ の暦日。UTC 日付を今日にしない
- オフラインファースト。API ダウンでも記録できる
- 同期 API の `local_date` はクライアントが決めた YYYY-MM-DD。サーバは TZ 変換しない
- ID はモバイル UUID / API ULID。DB 時刻は timestamptz
- ストア提出は必須ではない

## 6. 機能要件

| ID | 要件 | なぜ |
| --- | --- | --- |
| FR-01 | 今日のチェックが主操作 | SNS を足さない |
| FR-02 | 毎日ストリークは飛ばした日で切れる。今日未チェックだけでは切れない | 日付境界 |
| FR-03 | 週 n 回は ISO 週（月曜始まり）でクォータ | 週次習慣 |
| FR-04 | UTC 日付を今日にしない | TZ 誤用防止 |
| FR-05 | API は所有者以外 404 | 隔離 |
| FR-06 | シードは架空 | プライバシー |
| FR-07 | 統計画面が直近 30 日の完了率とストリークを習慣ごとに出す | 続きの実感 |

## 7. 非機能

| ID | 要件 | なぜ |
| --- | --- | --- |
| NFR-01 | ストリークと統計の純関数テストは DB なし | CI |
| NFR-02 | 単体 Compose で API の `/health` `/ready` が上がる | 単独デモ |
| NFR-03 | モバイルと API を Kubernetes に載せない | 実行基盤の方針 |
| NFR-04 | README に学習用であることと通知未実装を書く | 過大広告を防ぐ |

## 8. 受け入れ

1. Expo で今日のチェックが SQLite に残る
2. `npm test`（domain）が TZ・年末・統計ケースで緑
3. API `npm test` が隔離で緑
4. 統計画面で 30 日窓の完了率とストリークが見える
5. Compose で `/health` `/ready` と `demo` の 5 習慣
6. ローカル通知は受け入れに入れない
