## 1. 今日

端末の IANA タイムゾーンで `YYYY-MM-DD` を決める。例: `2026-08-18T16:30:00Z` は `Asia/Tokyo` では `2026-08-19`、`America/Los_Angeles` では `2026-08-18`。

## 2. チェック

習慣行のチェックは当該 TZ の今日を完了/未完了にする。詳細カレンダーでは任意の暦日をトグルできる（デモ用。履歴改ざん防止は未実装）。

## 3. ストリーク

毎日: 完了集合を、今日が完了なら今日から、さもなくば昨日から、連続する暦日だけ数える。昨日も今日も未完了なら 0。年末（`2025-12-31` と `2026-01-01`）は連続。

週 n 回: ISO 週（月曜始まり）。その週の完了日数 ≥ n なら達成。今週未達でも先週が達成ならストリークは維持。1 週飛ばすと切れる。

## 4. カレンダーと統計

カレンダーは月曜始まり 6×7。当月外のセルは薄いがトグルは可能。完了は色塗り。

統計画面がある。直近 30 日の完了数・完了率と現在ストリークを習慣ごとに出す。通知・差分同期・OIDC・アーカイブ UI・CSV は未実装。
