| 項目 | 値 |

| プロダクト | 勤怠 [pf-attendance](https://github.com/maeplego/pf-attendance) |

| 実装との関係 | この文書と実装が違うときは、製品リポジトリのコードとテストを優先する |

## 1. 背景と目的

出退勤と休憩をイベントとして残し、その日の労働時間を休憩控除つきで整数分にする。Excel 転記の代わりに、日付境界をコードで固定するのが価値である。予約カレンダー [pf-calendar](https://github.com/maeplego/pf-calendar) とは統合しない。公開スロットと労務計算は別境界である。

学習用であり、本番勤怠や給与計算、労基法の完全準拠ではない。スタックは業務寄りの Java / Spring Boot + Next.js。

## 2. 含む

- 架空の従業員マスタ（開発部 8 名）
- 出勤 / 退勤 / 休憩開始 / 休憩終了の打刻（追記。上書きしない）
- サーバー時刻の採用。クライアントの `punchedAt` は無視
- 勤務日は Asia/Tokyo の暦日。23:59 と 00:00 は別日
- 日次労働時間（休憩控除、整数分）
- 月次カレンダー UI（`/calendar`）と `GET /v1/me/month-summary`
- 他人の打刻が日次・月次に混ざらないこと
- 不正な順序は 409
- 単体 Compose（Postgres + API + 打刻 Web）

## 3. 含まない

| 項目 | 理由 |
| --- | --- |
| 修正・休暇申請と承認 | 未実装 |
| 工数按分 | 未実装 |
| 月次締め・CSV・締め後 409 | 未実装 |
| 未打刻リマインド、認証基盤の OIDC | 未実装 |
| 夜勤、給与、IC カード、シフト最適化 | 範囲外。中途半端に夜勤を入れない |
| overlay F | 任意の連携デモ |

## 4. アクター

| アクター | 定義 | 認証 |
| --- | --- | --- |
| 従業員 | 自分の打刻、本日サマリー、月次カレンダー | `X-Dev-User-Sub` |
| 上長 | シード上の role のみ。他人閲覧の本格 ACL は未実装 | 同上 |

## 5. 前提

- ID は ULID。時刻は `timestamptz`（UTC）。勤務日は Tokyo の `DATE`
- 労働時間は整数分。秒は切り捨て
- 日勤のみ。勤務日フィールドを打刻時刻から決める
- 金額は出さない（給与計算しない）

## 6. 機能要件

| ID | 要件 | なぜ |
| --- | --- | --- |
| FR-01 | 打刻はイベント追記。サーバー時刻 | 改ざんと「なかったこと」を防ぐ |
| FR-02 | 勤務日は Asia/Tokyo。23:59 と 00:00 は別日 | 日付境界の説明 |
| FR-03 | 日次労働は休憩区間を控除した整数分 | 業務システムの核 |
| FR-04 | 順序違反（二重出勤、休憩中退勤など）は 409 | 不正状態を作らない |
| FR-05 | 従業員 A の打刻は B の日次にも月次にも出ない | 認可はサーバ |
| FR-06 | シードは架空。実在個人は使わない | 公開前提 |
| FR-07 | 月次カレンダーで指定月の各暦日の状態と分数を見られる | 一覧の次の画面 |

## 7. 非機能

| ID | 要件 | なぜ |
| --- | --- | --- |
| NFR-01 | 日境界と分数のテストは DB なしで緑 | CI が Docker 無しでも回帰する |
| NFR-02 | Compose は専用 Postgres | 単独デモ |
| NFR-03 | README に学習用・非労基準拠・日境界表を書く | 誤用と過大広告を防ぐ |

## 8. 受け入れ

1. 09:00–18:00 相当（UTC では 00:00–09:00）で 12:00–13:00 相当の休憩を挟むと労働 480 分、休憩 60 分
2. `2026-08-18T14:59:00Z` の勤務日は 2026-08-18、`2026-08-18T15:00:00Z` は 2026-08-19
3. クライアントが `punchedAt` を付けてもサーバー時計になる
4. 他従業員の日次 punches は空。月次も混ざらない
5. `/calendar` で月を前後でき、各日の状態が見える
6. `docker compose up` で打刻画面が動く
