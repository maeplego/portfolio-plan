## 1. 画面

開発時の Web はヘッダ `X-Dev-User-Sub` で従業員を切り替える。既定のデモ利用者は `aoki.haru`。架空の 8 名をセレクトで選べる。`sato.mei` にすると青木の打刻は一覧にも月次にも出ない。

| 画面 | パス | できること |
| --- | --- | --- |
| 打刻ホーム | `/` | 出勤・休憩開始・休憩終了・退勤の大きいボタンと、本日の労働分・休憩分 |
| 月次カレンダー | `/calendar` | `YYYY-MM` を前後し、各暦日の状態と分数を格子で見る |

クライアントの時計は使わない。オフライン打刻は約束しない。申請・承認・締め・CSV・夜勤は未実装。

## 2. 打刻種別

| type | 意味 | 直前の状態 |
| --- | --- | --- |
| `clock_in` | 出勤 | `absent` |
| `break_start` | 休憩開始 | `clocked_in` |
| `break_end` | 休憩終了 | `on_break` |
| `clock_out` | 退勤 | `clocked_in` |

休憩中の退勤は 409（休憩未終了）。同日の二回目の出勤も 409。日が変われば新しい出勤が許される。

## 3. 時刻と勤務日

- 保存時刻: UTC の `timestamptz`
- 勤務日: その瞬間の Asia/Tokyo 暦日
- 日本に夏時間は無いので、23:59 と 00:00 の境界は固定オフセット +9 で足りる

| UTC | JST | 勤務日 |
| --- | --- | --- |
| 2026-08-18T14:59:00Z | 23:59 | 2026-08-18 |
| 2026-08-18T15:00:00Z | 00:00 | 2026-08-19 |

## 4. 日次・月次の労働時間

閉じた区間だけを足す。休憩開始〜終了は労働に入らない。秒は切り捨てて整数分。

本日（クエリ日付がサーバーの Tokyo 今日）に限り、未退勤・休憩中は `asOf=now` で開いている区間も分に含める。過去日の未完了は閉じた区間だけ（休憩未終了は `breakMinutes=0` のまま `on_break`）。

月次は指定月の暦日すべてを返す（8 月なら 31 行）。他人の打刻は 0 分・`absent`。

## 5. エラー

```json
{ "error": { "code": "conflict", "message": "already clocked in" } }
```

| 状況 | HTTP | code |
| --- | --- | --- |
| 開発ヘッダなし / 未知の sub | 401 | unauthorized |
| 未知の type、壊れた date / month | 400 | validation_error |
| 順序違反 | 409 | conflict |
| DB 不通 | 503 | `/ready` のみ |
