# Collab 初期 SLO・監査保持・脆弱性方針

| 項目 | 値 |
| --- | --- |
| 対象 | Collab 商用最小（契約で上書き可） |
| 最終更新 | 2026-08-21 |

本書で [production-definition.md](./production-definition.md) の Risk Accept（SLO・監査保持・High 脆弱性方針）を文書化する。数値は運用開始時に顧客契約で確定してよい。

## 初期 SLO（案）

| 指標 | 目標（初期） | 測定 |
| --- | --- | --- |
| 月次稼働 | 99.0%（計画メンテ除外） | `/health` 合成監視 |
| API 可用性 | 同左 | workspace API + IdP |
| 障害初動 | 営業時間 1 営業日以内の一次応答 | サポート契約 |

未契約の評価 LICENSE では SLO を請求しない。

## 監査ログ保持

| 項目 | 既定案 |
| --- | --- |
| 保持期間 | 90 日（契約で延長可） |
| 対象 | ログイン成否、トークン発行、org 切替、招待、権限変更 |
| 法務 | 顧客の業種・地域で確定。本既定はポートフォリオ／PoC 用 |

## 脆弱性（High 以上）

| 方針 | 内容 |
| --- | --- |
| 検出 | CI Trivy / Dependabot 等（各 `pf-*`） |
| 対応 | リリース前に High/Critical を修正、または下記例外表に記録 |
| 例外 | 修正不能・誤検知・受容。誰が・いつ見直すかを書く |
